A customizable **GitHub Profile README Generator & Editor**. Designed to help developers create profile READMEs with interactive inputs, section reordering, and animated widgets.

## Features

- **4 Interface Themes:** Switch between **Dark Mode (Space)**, **Cyberpunk (Neon)**, **Light Mode**, and **Emerald (Nature)**.
- **Section Reordering & Toggle:** Enable, disable, and sort sections (Header, About, Techs, Projects, Stats, Extras) using up/down controls.
- **Animated Widgets:** 
  - Dynamic waves header banner (Capsule Render)
  - Animated typing text subtitles (Typing SVG)
  - 3D-style achievement trophies (GitHub Profile Trophies)
- **Live Preview:** Immediate render of your markdown code.
- **One-Click Actions:** Copy to clipboard or download as a `README.md` file.
- **Responsive Layout:** Split layout optimized for desktop and mobile screens.

## Tech Stack

- **Core Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v3
- **Markdown Processing:** Marked
- **Animations:** Lucide Icons & Canvas Confetti

## Getting Started

Follow these steps to run the application locally on your computer:

### 1. Clone the Repository
```bash
git clone https://github.com/0umutekinci/github-readme-generator.git
cd github-readme-generator
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173/` to view the app.
